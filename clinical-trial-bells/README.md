# BELLS trial: prednisolone and acyclovir in Bell's palsy

**Status:** analysis of a published trial dataset (self-directed).

**Question:** do prednisolone or acyclovir, used early in Bell's palsy, improve the chances of recovery?

**Design of the trial:** randomised, double-blind, placebo-controlled, 2x2 factorial (prednisolone, acyclovir, both, or placebo).

**Methods:** data inspection and processing, descriptive tables (`gtsummary`), exploratory tests, visualisation.

- Code: [`r/scripts/analysis-for-bells.Rmd`](r/scripts/analysis-for-bells.Rmd)
- Output: [`r/outputs/analysis-for-bells-output.pdf`](r/outputs/analysis-for-bells-output.pdf)
- Data: [`data/raw/bells.csv`](../data/raw/bells.csv)

Source of the data: Sullivan FM et al., *Early treatment with prednisolone or acyclovir in Bell's palsy*, N Engl J Med 2007;357:1598-1607.
