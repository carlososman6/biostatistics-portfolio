# Practice

Early class exercises and short scripts in R, Stata and SPSS: frequencies, contingency tables, categorical variables and data wrangling. They show the starting point and are not part of the main portfolio. Datasets are in [`data/raw`](../data/raw). Rendered reports: [class assignments](r/outputs/class-assignments.pdf) and [first class data analysis](r/outputs/first-class-data-analysis.pdf). `class-1-frequencies.sps` has no dataset in the repository (it uses variables `height`, `weight`, `FEV` and `Bldgroup`), so it cannot be run as is.
